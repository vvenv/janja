# 生态

| 包 | 用途 |
| -- | ---- |
| [`janja-cli`](https://github.com/vvenv/janja/tree/main/packages/janja-cli) | 在命令行预编译、监听、检查和格式化模板 |
| [`vite-plugin-janja`](https://github.com/vvenv/janja/tree/main/packages/vite-plugin-janja) | 在 Vite 和 Rollup 构建中导入模板 |
| [`janja-express`](https://github.com/vvenv/janja/tree/main/packages/janja-express) | Express 视图引擎 |
| [`janja-koa`](https://github.com/vvenv/janja/tree/main/packages/janja-koa) | 为 Koa 提供 `ctx.render()` |
| [`janja-fastify`](https://github.com/vvenv/janja/tree/main/packages/janja-fastify) | 为 Fastify 提供 `reply.view()` |
| [`janja-language-server`](https://github.com/vvenv/janja/tree/main/packages/janja-language-server) | 面向所有 LSP 编辑器的诊断、补全、悬停提示和格式化 |
| [`eslint-plugin-janja`](https://github.com/vvenv/janja/tree/main/packages/eslint-plugin-janja) | 模板格式规则 |
| [`vscode-janja`](https://github.com/vvenv/janja/tree/main/packages/vscode-janja) | VS Code 中的语法高亮和语言服务器功能 |
