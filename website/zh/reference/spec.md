# Janja 语言规范

本文定义模板语言。[`spec/conformance.json`](https://github.com/vvenv/janja/tree/main/spec/conformance.json) 是它的可执行版本：下面每条规则在该文件中都有对应用例，参考实现在测试中运行全部用例。本文与用例集不一致时，以用例集为准，是本文写错了。

::: info
本页是[英文规范](/reference/spec)的译文，两者有出入时以英文版为准。
:::

## 1. 模板

模板是文本，其间穿插三种标签：

| 标签 | 默认定界符          | 用途                 |
| ---- | ------------------- | -------------------- |
| 输出 | `{{= expression }}` | 写出表达式的值       |
| 指令 | `{{ name ... }}`    | 控制流、定义、包含   |
| 注释 | `{{# text #}}`      | 写给模板作者看的说明 |

标签之外的一切都是文本，原样写出，包括换行符。

- 六个定界符都可以配置。
- 要写出本来会开始或结束标签的花括号，用反斜杠转义：`\{\{= a \}\}` 输出 `{{= a }}`。字符串字面量里同样适用。
- 指令名不区分大小写，其余一切都区分大小写。
- `{{ name }}` 中的 name 不是指令时报错（`Unknown "name"`）；输出一律用 `{{=`。

### 1.1 空白控制

紧贴定界符内侧的 `-` 会删掉标签该侧文本的全部空白（包括换行）：`{{- ... }}` 修剪标签之前的文本，`{{ ... -}}` 修剪标签之后的文本。输出标签的标记写在 `=` 之后：`{{=- value -}}`。所有标签都一样，嵌套在哪里都一样。

`trimWhitespace` 选项会修剪每段文本的两端。

### 1.2 注释

注释以 HTML 注释 `<!-- text -->` 的形式写入输出；设置了 `stripComments` 选项时不产生任何输出。注释里的标签不会被解释。

## 2. 数据模型

模板在一个*上下文*中渲染：一组具名的值，由渲染器的 `globals` 和渲染调用传入的数据叠加而成，后者优先。值就是 JavaScript 值。

- 模板从不修改传给它的数据。赋值是在模板自己的作用域里新建或遮蔽名称，过滤器返回新值。
- 以下每一种都会创建一个能看到外层名称的嵌套作用域：`for` 的每次迭代、`macro` 的每次调用。在里面赋值的名称在外面不存在。
- `if` **不**创建作用域：`if` 里的 `set` 在它之后仍然可见。
- `with` 创建的作用域*只*包含它的值的属性。

## 3. 表达式

### 3.1 字面量

| 种类   | 示例                                 | 说明 |
| ------ | ------------------------------------ | ---- |
| 数字   | `42`、`1.5`、`-2`                    | 仅十进制；没有指数，不能以 `.` 开头 |
| 字符串 | `"double"`、`'single'`、`` `tick` `` | 转义：`\n` `\t` `\r` `\\` 以及引号字符。其他反斜杠序列按原样保留，所以 `"\d+"` 是 `\d+` 三个字符 |
| 布尔   | `true`、`false`                      | |
| 空值   | `null`、`undefined`                  | |

没有数组和对象字面量；这类值通过数据传入。

### 3.2 名称与属性

- `name` 从上下文读取一个值。不存在的名称是 `undefined`。
- `a.b.c` 读取属性。点后面只能是标识符；没有 `a[b]`，也没有 `a.0`。读取 `null` 或 `undefined` 的属性会报错。
- `f(x, y)` 和 `a.b(x)` 调用上下文中的函数。
- 以下标识符在表达式的任何位置都禁止出现：`constructor`、`prototype`、`__proto__`、`__defineGetter__`、`__defineSetter__`、`__lookupGetter__`、`__lookupSetter__`。

### 3.3 运算符

除算术运算外，运算符是单词而不是符号。按结合力从松到紧：

| 级别 | 运算符                                       | 含义 |
| ---- | -------------------------------------------- | ---- |
| 1    | `x if test else y`                           | 条件。`else` 可省略；省略时条件为假得到空值 |
| 2    | `=`                                          | 赋值（`set`、过滤器的具名参数、默认值） |
| 3    | `or`                                         | 第一个为真的操作数，否则取最后一个 |
| 4    | `and`                                        | 第一个为假的操作数，否则取最后一个 |
| 5    | `eq` `ne` `gt` `ge` `lt` `le` `in` `ni` `is` | 比较 |
| 6    | `+` `-`                                      | 加法（也用于字符串拼接）、减法 |
| 7    | `*` `/` `%`                                  | 乘法、除法、取余 |
| 8    | `not`                                        | 取反 |
| 9    | `\|`                                         | 过滤器 |
| 10   | `.` 和调用                                   | 属性访问 |

- `eq` 和 `ne` 是严格比较：不做类型转换，`1 eq "1"` 为假。
- `a` 是 `b` 的键（或下标）时 `a in b` 为真；`ni` 是它的否定。
- `x is "type"` 把 JavaScript 的 `typeof x` 与一个字符串比较：`"number"`、`"string"`、`"boolean"`、`"object"`、`"undefined"`、`"function"`。
- `not` 比比较运算结合得更紧：`not a eq 2` 的意思是 `(not a) eq 2`。请写 `not (a eq 2)` 或 `a ne 2`。
- 圆括号用于分组：`(a + b) * 2`。
- 紧跟数字的 `-` 只有在期待操作数的位置才表示负数；在操作数之后它是减法，所以 `a -1` 和 `a - 1` 相同。名称没有一元负号。
- 真假值沿用 JavaScript：`false`、`0`、`""`、`null`、`undefined` 和 `NaN` 为假；其余都为真，包括空数组和空对象。
- 两个操作数之间没有运算符（`a b`）会报错。

### 3.4 过滤器

`value | name` 和 `value | name(arg, ...)` 以该值为第一个参数调用过滤器 `name`。过滤器从左到右串联。过滤器只作用于它前面的那一个操作数：`a + b | add(10)` 中过滤器作用于 `b`，要过滤整个表达式请加圆括号。

过滤器可以是异步的，模板会等待它。使用未注册的过滤器，会在表达式求值时报错。

## 4. 输出

`{{= expression }}` 写出表达式的值：

- `null` 和 `undefined` 不写出任何内容。
- 其他值按 JavaScript 的字符串转换处理（数组的元素用逗号连接，普通对象变成 `[object Object]`；结构化数据请用 `json` 过滤器）。
- 除非关闭了 `autoEscape`，结果会做 HTML 转义：`&` → `&amp;`、`<` → `&lt;`、`>` → `&gt;`、`"` → `&#34;`、`'` → `&#39;`。
- 标记为安全的值（`safe` 过滤器、`Safe` 对象、捕获的内容）不转义直接写出。

## 5. 指令

### 5.1 `if`

```janja
{{ if test }}...{{ elif test }}...{{ else }}...{{ endif }}
```

`elseif` 和 `elsif` 是 `elif` 的同义词。各分支按顺序测试，渲染第一个为真的分支。

### 5.2 `for`

```janja
{{ for item of items }}...{{ else }}...{{ endfor }}
```

- 可遍历数组、字符串（按字符）和其他任何可迭代对象。`null`、`undefined` 和不可迭代的值（包括普通对象）视为空；遍历对象请用 `keys`、`values` 或 `entries` 过滤器。
- 没有可遍历的内容时渲染 `else` 分支。
- `{{ for (a, b = default) of items }}` 读取每一项的*属性* `a` 和 `b`；属性为 `undefined` 时使用默认值。
- 循环体内，`loop.index` 是从零开始的位置，`loop.first` 和 `loop.last` 是布尔值。
- `{{ break }}` 结束最内层循环，`{{ continue }}` 跳到它的下一次迭代。在循环之外使用都会报错。

### 5.3 `set`

```janja
{{ set name = expression }}
{{ set (a, b) = expression }}
```

在当前作用域中赋值。第二种形式读取值的属性 `a` 和 `b`。赋值目标必须是普通名称。

### 5.4 `capture`

```janja
{{ capture name }}...{{ endcapture }}
```

渲染主体，把结果赋给 `name` 而不是写出。结果被标记为安全，之后写出时不会再次转义。

### 5.5 `with`

```janja
{{ with value }}...{{ endwith }}
```

在一个只由 `value` 的属性构成的作用域中渲染主体。里面的赋值不会修改 `value`。

### 5.6 `macro`、`caller` 和 `call`

```janja
{{ macro name(param, other = default) }}...{{ caller }}...{{ endmacro }}
{{ call name(arguments) }}...{{ endcall }}
```

宏是一段具名、带参数的模板。`call` 调用它；`call` 的主体渲染在宏中 `{{ caller }}` 所在的位置。参数按位置传递；参数缺失或为 `undefined` 时使用默认值。宏的主体能看到定义宏的位置上作用域内的名称，外加它的参数。在宏之外使用 `caller` 会报错。

### 5.7 `include`

```janja
{{ include "path" }}
```

在当前位置渲染另一个模板。路径是一个字符串字面量，交给渲染器的 `loader`；它代表什么由 loader 决定。被包含的模板能看到包含它的模板的顶层上下文，包括 `include` 之前在顶层赋值的名称。模板加载不到会报错。

### 5.8 `block` 和 `super`

```janja
{{ block name }}...{{ endblock }}
```

block 用来实现布局。一个模板及其包含的所有模板中的 block 按名称汇总：

- 每个 block 只渲染一次，位置是该名称的 block 第一次出现的地方。
- 在那里渲染的是该名称的*最后一个*定义。因此页面先包含布局，再重新定义想替换的 block。
- block 里的 `{{ super }}` 渲染被它替换掉的那个定义，可以跨多层连用。在 block 之外使用会报错。

## 6. 错误

符合规范的实现需要报告下列错误，并给出在模板中的位置：

- 编译期：格式错误的标签和表达式、未知指令、指令缺少必需的表达式或带了不该有的表达式、未闭合的块、没有对应开头的结束指令或分支指令、被禁止的标识符、加载不到的模板；
- 渲染期：读取空值的属性、调用不是函数的东西、未知的过滤器，以及过滤器或函数抛出的错误。

默认情况下，第一个错误就中止渲染。宽松模式下（提供了 `debug` 处理函数），每个错误都交给处理函数：出错的指令被跳过，未闭合的块在模板末尾闭合，未知和不该出现的指令写成 HTML 注释，渲染期失败的模板产生空字符串。

对任何输入，解析都会终止。
